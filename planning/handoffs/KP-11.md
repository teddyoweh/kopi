# KP-11 — Agent: Claude Agent SDK runner and Kopi MCP tools

**Built**
- **`kopi/agent/tools.py`**: the in-process MCP server `kopi` with seven read-only tools:
  - `search_tenders`, `get_tender`, `check_eligibility`, `similar_awards`,
    `find_licences`, `get_company_profile`, `submission_checklist`.
  - Every tool goes through the Kopi API with the session token. There's no direct
    NeedleDB access and no keys in the sandbox.
  - Notice text comes back inside `<notice doc_no=…>` delimiters, and any `<notice` or
    `</notice` inside the text is escaped.
  - The submission checklist is built by rules from the notice plus the eligibility
    checks.
- **`kopi/agent/prompts.py`**: a bid-desk system prompt covering the four parts, the
  rules on untrusted notices, "Kopi prepares, the person submits", and where drafts go.
- **`kopi/agent/runner.py`**: `python -m kopi.agent.runner --message … --profile-file …
  [--resume …] [--doc …]`. It prints one `ChatEvent` JSON line per event: streamed text
  deltas, `tool_call`, a one-line `tool_result`, a `file` when a draft lands, then `done`
  with cost, or `error` then `done`.
- **Tests:** 23 in `tests/test_agent.py`. The tool handlers run against the *real* FastAPI
  app over fixtures, because Starlette's TestClient is an httpx client.

**Lockdown** (see planning/research/agent-sdk.md)
- `tools=["Read","Write","Edit","Glob"]` is the only built-in set that *exists*, so
  Bash and WebFetch simply aren't there. `disallowed_tools` names them anyway.
- `permission_mode="dontAsk"`, `strict_mcp_config=True`, `setting_sources=[]`,
  `max_turns=16`, and `max_budget_usd` from `KOPI_MAX_BUDGET_USD` (default 2.0).
- **A `PreToolUse` hook fences the file tools:** Read and Glob stay inside the workspace,
  and Write and Edit only reach `drafts/`. It's tested against `/etc/passwd`, `~/.ssh`
  and `drafts/../../escape.md`.

  we're eligible for, then draft clarification questions for the best one."

  - `check_eligibility` on 7 tenders;
  - `get_tender` on the best two;
  - a `Write` of `drafts/MOE000ETQ26000222-clarification-questions.md`.
- **Cost:** $0.18.
- **The draft:** 14 numbered questions, each with why it matters for pricing, grounded

**The agent found a bug in our rules, and I fixed it here.** `eligibility.closing_check`
said "closes today" for a tender closing at 13:00 the next day, because it counted
24-hour periods. The agent noticed the mismatch against the date it had been given and
said so in its answer. It now counts Singapore calendar days ("today", "tomorrow",
"in N days"), with a regression test. This edits KP-4's `eligibility.py`: a one-function
bug fix, noted here.

**For KP-12 (sandbox)**
- Run `python -m kopi.agent.runner` inside the sandbox with `--workspace /workspace`,
  and write the profile JSON to a file first.
- The environment needs `KOPI_API`, `KOPI_SESSION_TOKEN` (scoped, short-lived) and
  `CLAUDE_CODE_OAUTH_TOKEN`.
- Read stdout line by line; each line is a ChatEvent. Use `session_id` from any event
  for `--resume` on the next turn.
- Drafts land in `/workspace/drafts/`. Copy them out after each turn.

**Decisions**
- **Streamed text is deltas.** `include_partial_messages=True`, and only top-level
  deltas are streamed (not a subagent's), so full `TextBlock`s aren't repeated.
- **A failed tool result says so** in its summary ("Error: …"). I didn't add a field to
  `ChatEvent`, because KP-13 mirrors that type by hand.
- **`KopiClient` raises its own `ApiError`** on non-2xx rather than relying on the HTTP
  library's exception type.

**Where the agent went wrong**
- **HTTP library mismatch.** Errors were first caught as `httpx.HTTPStatusError`, but
  the test client is built on `httpx2`, so a 404 escaped as an exception instead of
  becoming a tool error. Production would have worked only because it happens to use
  `httpx`. Fixed by checking the status code in `KopiClient` and raising `ApiError`.
- **Relative drafts path.** The first prompt told the model to write to a relative
  `drafts/…` path. Claude Code's Write tool expects absolute paths, so the prompt now
  gives the absolute drafts folder, and the guard resolves relative paths against the
  workspace either way.
- **Placeholder lambdas.** The first `tools.py` used `noqa`'d lambdas for the checklist
  and money formatting. Replaced with named functions and comprehensions before commit.
