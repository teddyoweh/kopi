# KP-29 — Rounder, thinner, calmer UI on every page

**Built**
- **Tokens** (`web/app/globals.css`):
  - radius scale set explicitly: sm 6, md 10, lg 12, xl 16, 2xl 18, 3xl 24 (px);
  - hairlines #ebebed and inputs #e2e2e5; muted text #6b6b70; fills #f4f4f5;
  - a `font-book` weight (450);
  - lucide icons drawn at 1.75px, but only where the icon kept lucide's default of 2, so
    an explicit `strokeWidth` still wins;
  - Inter loaded with its `opsz` axis (`web/app/layout.tsx`).
- **Primitives:**
  - buttons, badges, filter chips, the search field and the context chip are pills;
  - inputs are 36px with a 10px radius and an indigo focus ring;
  - menus are 16px with 10px items;
  - right-hand sheets (draft preview, drafts) float 8px from the edge with an 18px radius.
- **Lists:**
  - `ListCard` has a quiet 48px header instead of a grey strip;
  - rows are rounded hover targets separated by inset hairlines, which fade while either
    neighbour is hovered (`ROW` in `tender-row.tsx`, using a plain `kopi-row` marker class
    in the sibling selector);
  - static lists (eligibility, suppliers, registrations, checklist) use `divide-y
    divide-border/70` in 16px cards.
- **Pages:**
  - overview: the three stats in one divided card, with short labels under 640px;
  - tender: a 28px weight-500 title, with the closing badge tinted and red at three days or
    fewer;
  - properties, verdict, market figures and notes are soft grey surfaces;
  - AI overview: header without a strip, with a tinted icon disc;
  - "Prepare a response": borderless rows with tinted icon discs;
  - copilot: a 24px composer, pill context chip, example cards with icon discs, and a user
    bubble with a tail corner;
  - submissions groups have quiet headers; ticked items are struck through;
  - profile: pill segmented control and pill save bar;
  - licences: pill "Try" chips and a soft facts panel;
  - access gate: a 24px card.
- **`displayTitle()`** (`web/lib/title-case.ts`) turns GeBIZ's all-caps titles into title
  case and leaves every other title alone.
  - Applied to tender rows, the tender heading, submissions, the copilot context chip,
    past-award descriptions and supplier names.
  - Checked against all 727 open titles: exactly the 162 all-caps ones change.
  - It keeps:
    - acronyms (CCA, HDB, M&E, (SHM), CHIJ, SCAR);
    - reference numbers (SPO-REQ-2026-005662-SS, MAS-REQ-…/AA);
    - labels ("Part A", "Pt B").
  - It restores:
    - months and abbreviations ("1 Jan", "Pri Sch", "Pte. Ltd.");
    - Singapore place syllables ("Pasir Ris", "Toa Payoh", "Pei Chun").

**Checked**
- `npm run lint` is clean, and the mock and live builds both succeed.
- Every page was screenshotted at 1440 and 390, on live data and in mock mode (for the
  copilot turn and draft sheet), with no console errors and no horizontal overflow. Saved
  as `artifacts/media/kopi/round-*.png`.

**For the next agent**
- Titles from GeBIZ go through `displayTitle()` wherever they are shown. Don't show a raw
  `notice.title`.
- New clickable list rows use `ROW` from `tender-row.tsx`; new cards use `rounded-xl
  border`.
- A surface inside a card is `bg-muted/60`–`/70` with no border.

**Where the agent went wrong**
- My first all-caps rule was sentence case. Reading the real titles showed it would lower
  names, so I switched to title case before writing any UI.
- The first pass kept "Pasir RIS", "TOA Payoh" and "in-House". I fixed the rule for
  compound first pieces and added the place syllables, then re-ran it over all 727 titles.
- The icon stroke rule first overrode every lucide icon, including the ones given an
  explicit `strokeWidth` (the send arrow and the checkbox tick). I narrowed it to
  `svg.lucide[stroke-width="2"]`.
- The row selector first used a `group/row` name, whose escaped slash would not have
  matched between the source and the DOM. I replaced it with a plain `kopi-row` marker
  class.
