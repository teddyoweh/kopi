# KP-25 — Linear design system and app shell

**Built**
- **Tokens** (`web/app/globals.css`), sampled from Teddy's Linear screenshot, not guessed:
  - frame and sidebar #efeff0; panel #fcfcfc; cards and popovers white;
  - fills #f3f3f4; hairlines #e2e2e2; active row #e1e1e2; sidebar hover #e7e7e8;
  - text #1b1b1b, muted #5c5c5e;
  - `--kopi` and `--primary` are Linear indigo #5e6ad2 (soft tint #eef0fb). The
    met/unmet/unknown colours are unchanged.
  - New utilities: `bg-frame`, `bg-sidebar-hover`, `shadow-float` (floating surfaces only).
  - Radius base 0.5rem, so `rounded-md` is 6px and `rounded-xl` about 11px.
- **Font:** Inter via next/font. Geist Mono stays for monospace.
- **Shell** (`components/shell/app-shell.tsx`):
  - the frame holds a 240px sidebar;
  - content sits in an inset panel (`#kopi-panel`, 8px from the frame, rounded, hairline),
    which is the scroll container;
  - its sticky 52px top bar shows the section by default (icon and label) until the page
    names itself.
  - Mobile: the panel is full-bleed, and a menu button opens the sidebar in a sheet.
- **Sidebar:**
  - the company profile as Linear's workspace switcher, beside a search icon and a round
    "new chat" button;
  - nav in three groups: Overview, Copilot and Submissions (with the tracked count), then
    foldable "Explore" (Search, Licences) and "Company" (Profile).
- **`PageHeader`** portals `title`, optional `crumbs` and `actions` into the top bar through
  `usePanel()`, and renders `description` as the page's opening line. `SectionHeader` is now
  14px semibold.
- **Primitives:**
  - buttons: 6px radius, 13px text, indigo primary, white outline buttons with hairlines;
  - badges: squared; inputs: white with a hairline;
  - menus: hairline plus `shadow-float`; tooltips: compact and dark;
  - filter chips: bordered 28px pills, indigo-tinted when set;
  - search field: white, hairline, indigo focus;
  - empty and error states: bordered cards;
  - sign-in card: on the frame.
- **Screenshots** at 1440 and 390 (mock mode) show the shell; the page bodies are KP-26 and
  KP-27. Two are in `artifacts/media/kopi/linear-shell-*.png`.

**For KP-26 and KP-27**
- Name the page with `<PageHeader title crumbs actions description />` instead of an H1.
  For example, the tender page should use `crumbs={[{ label: "Overview", href: "/" }]}` and
  put Track and GeBIZ in `actions`.
- **The panel scrolls, not the window.** `usePanel().scroller` is the element. The copilot's
  stick-to-bottom currently reads `window.scrollY`, `window.innerHeight` and
  `document.documentElement.scrollHeight`, and those must move to the scroller.
- A sticky element inside a page sticks to the panel. The top bar is 52px, so use
  `top-16` or more.
- Use the tokens (`bg-card`, `border`, `bg-muted`, `text-muted-foreground`, `text-kopi`),
  not hex values. Hairline-bordered cards are `rounded-lg border bg-card`, and list rows
  are `border-b` with a hover fill.
- For a mock-mode build: `NEXT_PUBLIC_KOPI_API=mock npm run build`. An empty value is not
  mock mode, and `.env.production` otherwise supplies the live origin.

- **The mobile sheet's own close button sat on top of the new-chat button.** Found in the
