# KP-39: Command palette, keyboard shortcuts and toasts

**Done**
- **⌘K palette** (`web/components/command/palette.tsx`, on a Base UI Dialog in `surface.tsx`). It opens with ⌘K, Ctrl+K or `/`.
  - **Empty query.** Groups: This tender (on `/tender` and `/bid`: Start or Open bid, Ask Kopi, Open the tender, View on GeBIZ, Copy link), Recent, Your bids, Go to (each with its chord), and Actions (New chat, Bid as <other company>, Keyboard shortcuts).
  - **Typed query.** The local groups filter at once. Tenders come from semantic search (debounced 200 ms, stale answers dropped). A GeBIZ document number jumps straight to the tender. Licences come from `searchLicences`. "Search all tenders" and "Ask Kopi" always come last.
  - On `/tender` and `/bid`, a context chip with the doc number sits above the input.
- **Shortcuts** (`web/lib/shortcuts.ts`). One table drives both the global handler and the `?` sheet (`shortcuts-sheet.tsx`):
  - general keys: `c` for a new chat, `?` for the sheet;
  - chords `g h/i/c/b/s/l/p` for the pages;
  - the search page's own `j/k/↵/b`.
  - The handler listens in the capture phase. It ignores keys typed into fields and keys pressed while another dialog or menu is open. ⌘K works everywhere.
- **Toasts** (`web/components/ui/toast.tsx`). This is a module-level store: `toast({ title, description?, icon?, action?: { label, href? | onClick? }, duration? })`, plus `dismissToast(id)` and `<Toaster />`.
  - Layout: bottom-right on desktop, full width on a phone, three at most, paused while hovered.
  - Used for Copy link, switching company, and an upload landing in a bid.
- **Recents** (`web/lib/recents.ts`). `recordVisit` runs when a tender page loads and keeps the 8 newest.
- **Mounting.** `web/app/layout.tsx` wraps `AppShell` in `CommandProvider` (inside `KopiProvider` and `TooltipProvider`), with `<Toaster />` beside it.
- **Screenshots** at 1440 and 390, in `artifacts/media/kopi/palette-*.png`: empty on Home, on a tender with the context group, "cleaning", a doc number, the shortcuts sheet, and toasts.

**Decisions**
- **No `cmdk` dependency.** A dialog, an input and a flat list of rows are about 400 lines. They carry the repo's own styles and need no line in 02-decisions.
- **One shortcut table.** The sheet can never document a key that the handler doesn't fire, and the reverse holds too.
- **Capture-phase listener.** The second key of a chord (`g b`) must not also reach the search page's `b` (start bid).
- **Remote groups append below the local ones.** Results arriving mid-typing never move the active row.

**For the next agent**
- `useCommand()` from `@/components/command/command-provider` returns `{ openPalette(query?), openShortcuts() }`. The sidebar's search icon and help button call these.
- `toast(...)` can be called from anywhere under the layout. It needs no hook.
- The palette's Go to list and icons come from `SHORTCUTS`, and its icons should match the sidebar's (Home is a house).
