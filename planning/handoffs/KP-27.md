**Decisions**
- **Three examples, not four parts.**
  - Without a tender, the cards are find tenders, draft clarification questions, and this
    week's bids. The licence starter was dropped because it asks about security screening,
    which fits one trade and not the profile.
  - With a tender, the cards are fit, registrations and licences, and clarification questions.
    The submissions question was dropped because the tender page's "Build submission
    checklist" and the Submissions page already cover it.
- **One composer element in both layouts**, with only its wrapper's classes changing. If
  it remounted on the first send, the cursor would leave the box.
- **The panel height is a calc, not `h-full`.** `FILL` is 100dvh less the 52px bar and the
  page's top padding:
  - `pt-6` below `sm`, `pt-8` from it;
  - from `lg`, 18px more for the inset (8px on each side, plus the border).

  `-mb-16` cancels `main`'s `pb-16`, so the composer rests on the panel floor. **If the
  shell's padding or bar height changes, update `FILL`.**
- **The rail is hidden in the empty state.** A fresh conversation has no session and nothing
  to list, and Linear Agent's empty screen is a single centred column.
- **Sans-serif everywhere, except fenced code blocks.** The mono font is gone from doc numbers,
  file names, tool inputs, the error reason, inline code, the UEN and registration codes. A
  fenced block is literal code, so it stays mono.
- **"Bidding as" moved to the top bar.** It is a page-level action, like Linear's workspace
  pickers, and it frees the body for the section cards. The old "Active profile" radiogroup is
  gone. The GRA, BCA, licences and bizSAFE radiogroups keep their names.
- **No new dependency, and no new token.** Everything uses KP-25's tokens, so there is no
  `02-decisions.md` entry.

**For the next agent**
- **Wrap `buttonVariants()` in `cn()` when it styles a `<Link>` or `<a>`.** On its own it
  leaves both `border-transparent` and `border-border`, and the transparent one wins, so
  outline links render without a border. `Button` merges its classes itself. Every use is
  wrapped now: mine, and `tender-ai.tsx`, which already was.
- **The sidebar's round "New chat" button links to `/copilot`, which continues the tab's
  conversation.** To make it start afresh, the shell must link to something like
  `/copilot/?new=1` and the copilot must reset on it. Not built; the shell is outside this
  slice.
- **`/copilot/` after `/copilot/?doc=X` keeps X in context**, because the tab's conversation
  remembers its tender (KP-13 behaviour). Scripts that expect "All open tenders" must remove
  the chip first.
- **Accessible names the checks rely on:**
  - the composer: "Message Kopi", "Send", "Stop the answer";
  - the copilot: "New conversation", "Remove the tender from this conversation", and "Open"
    (draft rows);
  - Submissions: "Show checklist" and "Hide checklist";
  - Profile: "Save profile", "Discard", "Reset to seed", "Reset";
  - the top-bar picker: "Bidding as X. Change the active profile".

**Where the agent went wrong**
- **Outline links without a border.** I copied KP-13's
  `className={buttonVariants({ variant: "outline" })}` onto the new "Find tenders" action, and
  the 1440 screenshot showed it borderless. KP-13's "Ask Kopi" and "Submit on GeBIZ" links,
  and the 503 state's browse links, had the same bug. Fix: `cn(buttonVariants(...))`.
- **Inline code stayed monospace** after I removed `font-mono`, because Tailwind's preflight
  gives `code` the mono stack. It needed an explicit `font-sans`. My first fix also added
  `break-all`, which split "clarificat|ion" mid-word; I took it out.
- **My first screenshot run crashed.** I assumed `/copilot/` opens empty, but the `?doc=` visit
  just before it had given the tab's conversation a tender. The app was right and the script
  was wrong. The script now removes the chip first.
- **Found only by reading screenshots:**
  - with `justify-between`, the example titles sat at different heights when descriptions
    wrapped to two and three lines. They now use a fixed gap, and the long description is
    shorter;
  - at 15px, `leading-7` made answers and lists read loose. They now use 1.6;
  - the progress ring looked like a loading spinner. It is now Linear's pie;
  - checklist rows ran to three lines each. Source and due now sit on the right from `sm`;
  - a tender's chip title stretched across the whole composer. It is now capped at 16rem.
